    Dieses Dokument greift ein ähnliches Dokument aus dem Jahr 1991 für Oracle auf und passt es an SGBD Firebird an. Im Jahr 1991 stammte der Kern des Dokuments aus der offiziellen Dokumentation von ORACLE und in einigen Punkten aus einem damals hervorragenden Werk von Christian MAREE und Guy LEDANT: SQL „Einführung, Programmierung und Beherrschung“, erschienen bei EYROLLES. Meines Wissens ist dieses Buch nicht mehr erhältlich. Die Autoren haben ein neues Buch verfasst, das ich noch nicht lesen konnte: SQL „2: Einführung / Programmierung“.

    SQL (Structured Query Language) ist eine Standardsprache zur Erstellung, Pflege und Abfrage relationaler Datenbanken. Sie ist weitgehend unabhängig vom verwendeten SGBD. Auch wenn die Beispiele in diesem Dokument mit dem SGBD Firebird geschrieben wurden, lassen sie sich dennoch größtenteils mit jedem relationalen SGBD nachstellen. Unter Windows gibt es verschiedene SGBD: freie Produkte wie MySQL, Postgres, Firebird, SQL Express 2005 sowie kommerzielle Produkte: Access, SQL Server, Oracle. Diese Datenbanken unterstützen alle die SQL-Sprache, jedoch manchmal mit proprietären Varianten, oft in Form von Erweiterungen der Standard-SQL-Sprache.

    Firebird wurde ausgewählt, da es die Eigenschaft besitzt, eine Datenbank in einer einzigen Datei zu kapseln. Für Studierende ist es daher praktisch, diese Datei auf einen USB-Stick zu kopieren, um sie auf ihrem eigenen Computer oder auf den Computern ihrer Schule oder Universität zu nutzen.

    Dieses Dokument richtet sich an Anfänger oder Personen, die ihre Kenntnisse über SQL auffrischen möchten. Es erhebt keinen Anspruch darauf, SQL vollständig abzudecken. Programmierkonzepte (gespeicherte Prozeduren, SQL-Programmierung, API, SQL) werden beispielsweise ebenso wenig behandelt wie die Verwaltung eines SGBD.
